
SGTS - SafeGuard Technologies
React + Vite + Tailwind starter project

QUICK START:
1. Install Node.js (v16+ recommended)
2. In project folder:
   npm install
   npm run dev
3. Open browser at http://localhost:5173

NOTES:
- Replace placeholder assets in src/assets (logo, drone-placeholder.mp4, story image).
- To build for production: npm run build
- To preview the production build locally: npm run preview
- Deploy to Netlify/Vercel by connecting the repo (or drag-and-drop the `dist` folder after build).

TAILWIND:
Tailwind is configured in tailwind.config.cjs; styles live in src/index.css.

WANT HELP DEPLOYING?
I can give step-by-step Netlify/Vercel instructions once you run the site locally and confirm everything looks right.
